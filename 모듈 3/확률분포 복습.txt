# 확률분포 (probability distribution)
- 확률변수가 특정한 값을 가질 확률을 나타내는 함수 

# 확률분포의 종류
1) 이산확률분포(discrete probability distribution): 셀 수 있음
2) 연속확률분포 (confinuous probability distribution): 셀 수 없음 


# 확률질량함수(pmf, probability mass function) - 이산형 
- 이산 확률 변수에서 "특정 값"에 대한 확률을 나타내는 함수
ex) P(X=x) = 1/6, x=1,2, ~ 6

# 확률밀도함수 (pdf, probability density function) - 연속형
- 연속확률변수에서 "특정구간"에 포함될 확률을 계산하는 함수 
- pdf에서 특정 값이 될 확률은 0임 (적분하면 0임) ex) P(X=2) = 0

# 누적분포함수 (cdf, cumulative distribution function) - 이산형 
- 주어진 확률 변수가 특정 값보다 작거나 같을 확률
- Fx(x) = P(X <= x) -> 이산형에서는 시그마 사용

# 누적분포함수 (cdf) - 연속형
- 주어진 확률 변수가 특정 값보다 작거나 같을 확률
- Fx(x) = P(X <= x) -> 연속형에서는 적분 사용

1. 이산형 확률 분포

# 균일 분포 (uniform distribution) 
- 확률변수가 특정 값을 가질 확률이 모두 동일한 분포 
P(X=x) = 상수
- 베이지안에서 사전확률 P(Y)를 구할 때 균일분포를 활용함 (정보가 없으니 균일분포를 활용하는것)  

# 베르누이 분포 (bernoulli distribution)
- 확률변수가 가질 수 있는 값이 0,1. X = 0 or 1
- 1은 성공, 0은 실패
- 내가 관심있는 일이 발생하면 1 (ex) 불량이면 1, 정상이면 0
- 한 번 시행했을 때의 성공 횟수. 그러므로 최대값이 1. 베르누이 시행이라고도 함

# 이항분포 (binomial distribution)  
- 독립적으로 "베르누이 시행을 n번" 한 경우의 총 성공 횟수  
- 확률분포가 가질 수 있는 수는 0부터 n까지. X = 0,1,2 ~~ n
- 베르누이 분포는 이항분포에서 n=1인 경우이다. 
- 베르누이와 이항분포 파이썬 함수도 똑같음. 베르누이는 n=1인경우


# 포아송분포 (poisson distribution)  
- 단위시간동안 관심있는 이벤트가 몇 번 발생할 것인지를 나타내는 분포 
- 드물게 발생하는 사건에 대해 보통 적용함 
- 확률변수가 가질 수 있는 값은 0부터 무한대까지. X = 0,1, ~~ 무한대 
- 람다 : 단위시간동안 평균적으로 이벤트가 몇 번 발생하는지 통상적인 값이 알려져 있어야함 

ex) 단위시간동안 부품이 3개 이상 고장날 확률 - P(X>=3) 포아송분포.  


# 기하분포 (geometric distribution)  
- 처음 성공할 때까지 시도한 횟수(X)의 분포
- 처음 실패할 때까지 시도한 횟수(Y)의 분포
- Y = X - 1  : 마지막은 무조건 성공으로 끝나기 때문에 이러한 식 나옴 
- 확률변수가 가지 수 있는 수는 1부터 무한대까지. X = 1,2, ... ~~ 무한대

A. 
공통된 핵심 아이디어: “처음 성공할 때까지 기다리는 시간”

2. 연속형 확률 분포 

# 균일 분포 (uniform distribution)
확률 변수가 특정 값을 가질 확률이 모두 동일한 분포 
X ~ U(a,b)

# 정규 분포 (normal distribution)
뮤, 시그마 제곱
표준정규분포 X ~ N(0,1)

# 감마 분포 (gamma distribution) 
알파번째 사건이 발생할 때까지의 대기시간의 분포 - 이산형 기하분포에서도 ~때까지 라는 표현 있었음
확률변수가 가질 수 있는 값 0에서 무한대까지 
- 분포 모양이 변화무쌍함  

# 지수 분포 (exponential distribution)
다음사건(첫번째사건)이 발생할 때까지의 대기시간의 분포
확률변수가 가질 수 있는 값 0에서 무한대까지 
감마분포에서 알파=1인 경우
(ex) 제품의 고장까지의 시간 (제품수명)  

# 카이제곱분포 
감마분포의 특이한형태
감마분포에서 알파 = p/2, 베타 = 2
- 카이제곱검정에 활용

사실상 감마분포, 지수분포, 카이제곱분포가 한 묶음 - 감마분포로 묶임 

# 베타분포
알파, 베타라는 매개변수로 정의되는 확률분포
0,1사이에서 정의됨 (값이 0과 1 사이에 있음, 0과1 포함)
모양이 상당히 다채로움 
베이지안에서 사후확률을 정의하는 데 활용됨 (P(Y|X))
